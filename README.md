# DayZombi Hospedagem

Projeto preparado para GitHub + Render.

## Render
Build Command:
`npm install`

Start Command:
`npm start`

Cadastre no Render, em Environment, estas variáveis:

- FIREBASE_DATABASE_URL
- FIREBASE_SERVICE_ACCOUNT_JSON
- FIREBASE_WEB_API_KEY
- FIREBASE_WEB_AUTH_DOMAIN
- FIREBASE_WEB_DATABASE_URL
- FIREBASE_WEB_PROJECT_ID
- FIREBASE_WEB_STORAGE_BUCKET
- FIREBASE_WEB_MESSAGING_SENDER_ID
- FIREBASE_WEB_APP_ID

Não envie `.env` ou Service Account para o GitHub.
